## Goal

Complete the `tokra-log` plugin to achieve full Tauri API parity and stdlib Logger integration.

## Current State

**Implemented:**
- Basic log levels: `debug`, `info`, `warn`, `error`, `fatal`
- `trace` level via `TracingLogger` subclass
- Multiple targets with per-target level filtering
- File output via `Pathname` with rotation

- Custom `formatter` (Ractor-shareable)
- `Target` as immutable `Data.define`

### Prerequisites

#### Tokra::Config and AppManager (Required for Emit/Parity)

**Current deviation:** Tokra's `AppHandle` takes a hash; Tauri's holds an `AppManager` with a `Config`.

**Tauri structure:**
```
AppHandle { manager: Arc<AppManager<R>> }
AppManager { config: Config, listeners: Listeners, ... }
Config { identifier, product_name, version, app, build, bundle, plugins }
```

**Tokra structure (minimal for MVP):**
```ruby
Config = Data.define(:identifier, :product_name, :version)
AppManager = Data.define(:config, :webviews)  # webviews: Hash{String => Webview}
AppHandle.new(manager) → @manager.config, @manager.webviews
```

**Files to change:**
- `lib/tokra/config.rb` — new `Config < Data.define`
- `lib/tokra/app_manager.rb` — new `AppManager < Data.define`  
- `lib/tokra/app_handle.rb` — take `AppManager` instead of hash
- Update `Path::Resolver` to use `config.identifier`

```ruby
# WebviewLogger writes logs via emit
# Ruby Logger:     TRACE=-1, DEBUG=0, INFO=1, WARN=2, ERROR=3, FATAL=4
# Tauri LogLevel:  Trace=1,  Debug=2, Info=3, Warn=4, Error=5
# Formula: (severity + 2).clamp(1, 5)
class WebviewLogger
  def initialize(app_handle)
    @app_handle = app_handle
  end

  def add(severity, message = nil, progname = nil)
    msg = message || progname
    level = (severity + 2).clamp(1, 5)  # FATAL(4) → 5 (Error)
    @app_handle.emit("log://log", { message: msg.to_s, level: level })
  end
end
```

**Reference:** [plugins-workspace lib.rs:L324-355](file:///Users/kerrick/Developer/plugins-workspace/plugins/log/src/lib.rs#L324-355)

```rust
pub enum TargetKind {
    Stdout,
    Stderr,
    Folder { path: PathBuf, file_name: Option<String> },
    LogDir { file_name: Option<String> },
    Webview,
}

// Usage:
Target::new(TargetKind::Stdout)
Target::new(TargetKind::LogDir { file_name: Some("app".into()) })
Target::new(TargetKind::Folder { path: "/tmp/logs".into(), file_name: None })
```

##### Ruby (Tokra)

```ruby
module Tokra::Plugins::Log
  # Target accepts IO, Pathname, or TargetKind variants
  module TargetKind
    Folder = Data.define(:path, :file_name)  # path is Pathname
    LogDir = Data.define(:file_name)          # OS-specific: ~/Library/Logs/{app}/ on macOS
    Webview = Data.define                     # emit via event to WebView
  end
end

# Usage - Target.new accepts any of:
Target.new($stdout)                                          # IO directly
Target.new($stderr)                                          # IO directly  
Target.new(Pathname("logs/app.log"))                         # Pathname directly
Target.new(TargetKind::Folder.new(Pathname("/tmp"), "app"))  # Custom folder
Target.new(TargetKind::LogDir.new(file_name: "app"))         # OS log dir
Target.new(TargetKind::Webview.new)                          # WebView events

#   Linux/BSD:     ~/.local/share/{bundle_id}/logs/
#   Windows:       %LOCALAPPDATA%/{bundle_id}/logs/
#   Android:       {filesDir}/logs/
```

#### RotationStrategy

**Reference:** [plugins-workspace lib.rs:L120-129](file:///Users/kerrick/Developer/plugins-workspace/plugins/log/src/lib.rs#L120-129)

##### Tauri (Rust)

```rust
pub enum RotationStrategy {
    KeepAll,         // Rename to dated files, never delete
    KeepOne,         // Delete old file, start fresh  
    KeepSome(usize), // Keep N most recent dated files
}
```

##### Ruby (Tokra)

```ruby
module RotationStrategy
  KeepAll = Data.define           # shift_age: 'daily' (or large N)
  KeepOne = Data.define           # shift_age: 1
  KeepSome = Data.define(:count)  # shift_age: count
end
```

##### Implementation Strategy

**API parity with Ruby stdlib internals.** File naming differs (Ruby: `.0`/`.1`, Tauri: `_2026-01-31`) but semantic behavior matches:

| Tauri API | Semantic Meaning | Ruby `shift_age` |
|-----------|------------------|------------------|
| `KeepAll` | Never delete rotated files | `'daily'` (date suffix, keeps all) |
| `KeepOne` | Only active file, discard on rotate | `1` |
| `KeepSome(n)` | Keep N most recent files | `n` |

##### Conversion Method

```ruby
# In Target or RotationStrategy module
def self.to_shift_age(strategy)
  case strategy
  when RotationStrategy::KeepAll then 1000
  when RotationStrategy::KeepOne then 1
  when RotationStrategy::KeepSome then strategy.count
  else 0  # No rotation
  end
end
```

**Reference:** [plugins-workspace lib.rs:L395-549](file:///Users/kerrick/Developer/plugins-workspace/plugins/log/src/lib.rs#L395-549)

##### Rust (Tauri)

```rust
use tauri_plugin_log::{Builder, Target, TargetKind, RotationStrategy};
use log::LevelFilter;

tauri::Builder::default()
    .plugin(
        tauri_plugin_log::Builder::new()
            .targets([
                Target::new(TargetKind::Stdout),
                Target::new(TargetKind::LogDir { file_name: None }),
            ])
            .level(LevelFilter::Debug)
            .level_for("hyper", LevelFilter::Warn)
            .rotation_strategy(RotationStrategy::KeepAll)
            .max_file_size(10 * 1024 * 1024)
            .filter(|metadata| !metadata.target().starts_with("tokio"))
            .format(|out, message, record| {
                out.finish(format_args!("[{}] {}", record.level(), message))
            })
            .build()
    )
```

##### Ruby (Tokra)

```ruby
Tokra::Builder.default
  .plugin(
    Tokra::Plugins::Log::Builder.new
      .targets([
        Target.new($stdout),
        Target.new(TargetKind::LogDir.new(file_name: nil)),
      ])
      .level(:debug)
      .level_for("rack", :warn)
      .rotation_strategy(:keep_all)
      .max_file_size(10 * 1024 * 1024)
```

### TimezoneStrategy Implementation

**Plugin-level setting** (1:1 Tauri parity).

##### Tauri (Rust)

```rust
pub enum TimezoneStrategy {
    UseUtc,    // OffsetDateTime::now_utc()
    UseLocal,  // OffsetDateTime::now_local()
}
```

##### Ruby (Tokra)

```ruby
module TimezoneStrategy
  class UseUtc < Data.define
    def format_time(time) = time.utc
  end
  
  class UseLocal < Data.define
    def format_time(time) = time  # pass-through (Ruby default)
  end
end
```

##### Integration

Ruby Logger passes `Time.now` (local) to formatter. Our custom formatter uses `strategy.format_time(time)` before formatting.

### Log::Builder Implementation

**Programmatic Builder only** (1:1 Tauri parity - no JSON config).

##### Tauri (Rust)

```rust
pub struct Builder {
    dispatch: fern::Dispatch,
    rotation_strategy: RotationStrategy,
    timezone_strategy: TimezoneStrategy,
    max_file_size: u128,
    targets: Vec<Target>,
    is_skip_logger: bool,
}

// Usage
tauri_plugin_log::Builder::new()
    .targets([Target::new(TargetKind::Stdout)])
    .level(LevelFilter::Debug)
    .rotation_strategy(RotationStrategy::KeepOne)
    .build()  // returns TauriPlugin
```

##### Ruby (Tokra)

```ruby
class Builder
  def initialize
    @targets = DEFAULT_TARGETS
    @level = :debug
    @rotation_strategy = nil
    @timezone_strategy = nil
    @skip_logger = false
  end

  def targets(targets) = (@targets = targets; self)
  def target(target) = (@targets << target; self)
  def clear_targets = (@targets = []; self)
  def level(level) = (@level = level; self)
  def rotation_strategy(strategy) = (@rotation_strategy = strategy; self)
  def timezone_strategy(strategy) = (@timezone_strategy = strategy; self)
  def max_file_size(size) = (@max_file_size = size; self)
  def skip_logger = (@skip_logger = true; self)
  def build = Plugin.new(self)  # returns Plugin
end

# Usage
Log::Builder.new
  .targets([Target.new($stdout)])
  .level(:debug)
  .build
```
