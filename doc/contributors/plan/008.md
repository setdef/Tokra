# Tokra Clipboard Plugin Implementation Plan

Port Tauri's `tauri-plugin-clipboard-manager` to `tokra-clipboard` as a 1:1 Ruby port using the `arboard` crate.

---

## Architecture Conformance

### ADR-007: Ractor-Shareable Mutable State via Rust

> [!IMPORTANT]
> This plugin requires **shared mutable state** across Ractors. Per ADR-007, this MUST be implemented in Rust using `Mutex<T>` + Magnus's `frozen_shareable()`.

**Why Rust, not Ruby?**

| Mechanism | Ruby | Rust + Magnus |
|-----------|------|---------------|
| `Mutex` | **Unshareable** | `Send + Sync` ✓ |
| Frozen objects | Cannot mutate | Interior mutability via Mutex ✓ |
| Cross-Ractor calls | `Ractor::UnsafeError` | `rb_ext_ractor_safe(true)` ✓ |

A Ruby `Mutex` cannot be made Ractor-shareable. A Rust `Mutex<T>` can.

### ADR-005: Thin Binding Steady State (Revised)

ADR-005 estimated ~20 LOC Rust for clipboard. Per ADR-007, plugins with shared mutable state require additional Rust for the Mutex wrapper pattern:

- **~60-80 LOC Rust**: Mutex wrapper + methods + TypedData impl + rb_ext_ractor_safe
- **~30 LOC Ruby**: Thin wrapper delegating to native class

This remains "thin" — no business logic in Rust, only thread-safe access patterns.

## Thread Safety: The ADR-007 Pattern

### Rust Layer: `Mutex<Option<Clipboard>>`

```rust
pub struct RbClipboard {
    inner: Mutex<Option<arboard::Clipboard>>,
}

impl RbClipboard {
    fn read_text(&self) -> Result<Option<String>, Error> {
        let mut guard = self.inner.lock().unwrap();
        match guard.as_mut() {
            Some(clipboard) => clipboard.get_text().map(Some).or_else(|e| match e {
                arboard::Error::ContentNotAvailable => Ok(None),
                _ => Err(Error::new(ruby.exception_runtime_error(), e.to_string())),
            }),
            None => Err("Clipboard has been cleaned up"),
        }
    }

    fn cleanup(&self) {
        self.inner.lock().unwrap().take();  // Drop the clipboard
    }
}
```

This matches Tauri's `Mutex<Option<Clipboard>>` exactly.

### TypedData Configuration

```rust
unsafe impl magnus::TypedData for RbClipboard {
    fn data_type() -> &'static magnus::DataType {
        static DATA_TYPE: magnus::DataType =
            magnus::typed_data::DataTypeBuilder::<RbClipboard>::new(c"TokraClipboard::Native::Clipboard")
                .free_immediately()
                .frozen_shareable()  // <-- Enables Ractor shareability
                .build();
        &DATA_TYPE
    }
}
```

### Extension Initialization

```rust
#[magnus::init]
fn init(ruby: &Ruby) -> Result<(), Error> {
    // Mark extension as Ractor-safe (allows calls from non-main Ractors)
    unsafe { rb_sys::rb_ext_ractor_safe(true); }
    // ... define class and methods
}
```

### Ruby Usage

```ruby
clip = TokraClipboard::Native::Clipboard.new
Ractor.make_shareable(clip)  # Freezes but methods still work

# Use from any Ractor
Ractor.new(clip) { |c| c.write_text("From worker!") }
clip.read_text  # => "From worker!"
```

### Plugin-Scoped Errors

Each plugin defines its own error hierarchy under `Tokra::Plugins::<Name>`:

```ruby
# lib/tokra/plugins/clipboard.rb
module Tokra::Plugins::Clipboard
  # Base error for clipboard operations.
  class Error < Tokra::Error; end

  # Raised when another application holds the clipboard lock.
  # Platform-specific: Windows (after 5 retries), X11 (rare).
  # Never occurs on macOS.
  class ClipboardOccupiedError < Error; end

  # Raised when clipboard content is unavailable or incompatible.
  class ClipboardUnavailableError < Error; end
end
```

### ClipboardOccupied Error Details

This error occurs in **specific, deterministic circumstances**:

| Platform | When | Source |
|----------|------|--------|
| **Windows** | `clipboard.open()` fails after 5 retry attempts (5ms spacing) | `windows.rs:548-561` |
| **X11** | `set_selection_owner()` fails (rare, system-level) | `x11.rs:262` |
| **macOS** | **Never** (arboard uses pasteboard, no locking) | — |

**Tokra Mitigation:**
- The Rust `Mutex` serializes access within Tokra
- ClipboardOccupied only occurs from external application contention
- Wrapped as `Tokra::Plugins::Clipboard::ClipboardOccupiedError`

## JavaScript Frontend Strategy

> [!TIP]
> **Tokra uses Tauri's IPC protocol directly.** Developers can use `@tauri-apps/plugin-clipboard-manager` — no custom JavaScript required.

### Why This Works

Tokra extracts Tauri's JavaScript format strings via `rake sync:tauri` and uses them for WebView communication:

```ruby
# lib/tokra/native.rb
def self.emit_js_script(event, payload)
  format(@emit_template, emit_fn: "__TAURI_EMIT__", event:, payload:, ids: "[]")
end
```

Since Tokra speaks Tauri's protocol, any Tauri frontend JavaScript library works:

```html
<script src="https://unpkg.com/@tauri-apps/plugin-clipboard-manager"></script>
<script>
  // Works because Tokra implements the same invoke() protocol
  const text = await window.__TAURI__.clipboardManager.readText();
</script>
```

### Benefits

- **Zero additional code** — no JavaScript to write or maintain
- **True 1:1 parity** — users use the exact same JS library as Tauri
- **Automatic updates** — when Tauri updates their plugin, Tokra gets it free

### Documentation Requirement

RDoc for the plugin MUST include:

```ruby
# == JavaScript (Frontend)
#
# Tokra uses Tauri's IPC protocol. Use the official Tauri plugin:
#
#   npm install @tauri-apps/plugin-clipboard-manager
#
# Or via CDN:
#
#   <script src="https://unpkg.com/@tauri-apps/plugin-clipboard-manager"></script>
#
# Then in your frontend:
#
#   import { readText, writeText } from '@tauri-apps/plugin-clipboard-manager';
#   const text = await readText();
#   await writeText('Hello from Tokra!');
```

### Rust Implementation (~70 LOC)

#### [MODIFY] [clipboard.rb](file:///Users/kerrick/Developer/tokra/plugins/clipboard/lib/tokra/plugins/clipboard.rb)

```ruby
module Tokra::Plugins
  # Clipboard plugin for reading and writing to the system clipboard.
  #
  # This plugin provides Ractor-safe clipboard access using the ADR-007 pattern:
  # a Rust Mutex wrapping arboard::Clipboard, exposed via frozen_shareable().
  #
  # == Ruby (Backend) Usage
  #
  #   clipboard = app.clipboard
  #   text = clipboard.read_text
  #   clipboard.write_text("Hello")
  #   clipboard.clear
  #
  # == JavaScript (Frontend)
  #
  # Tokra uses Tauri's IPC protocol. Use the official Tauri plugin:
  #
  #   npm install @tauri-apps/plugin-clipboard-manager
  #
  # Then in your frontend:
  #
  #   import { readText, writeText } from '@tauri-apps/plugin-clipboard-manager';
  #   const text = await readText();
  #
  class Clipboard < Tokra::Plugin
    # Plugin name for configuration lookup.
    def name = "clipboard-manager"

    def initialize(app, config = {})
      super
      @native = TokraClipboard::Native::Clipboard.new
      Ractor.make_shareable(@native)
      
      # Register state for Manager extension trait
      app.manage(@native)
    end

    def read_text = @native.read_text
    def write_text(text) = @native.write_text(text.to_s)
    def clear = @native.clear

    # Handle IPC commands from frontend (via Tauri's invoke protocol).
    # Returns true if handled, false to pass to next handler.
    def extend_api(invoke)
      case invoke.command
      when "plugin:clipboard-manager|read_text"
        invoke.resolve(read_text)
        true
      when "plugin:clipboard-manager|write_text"
        write_text(invoke.payload["text"])
        invoke.resolve(nil)
        true
      when "plugin:clipboard-manager|clear"
        clear
        invoke.resolve(nil)
        true
      else
        false
      end
    end

    def on_event(event)
      return unless event.is_a?(Tokra::RunEvent::Exit)
      @native.cleanup
    end
  end
  
  # Extension trait for Manager (ADR-006 §5.7.1)
  module ClipboardManagerExt
    # Access the clipboard state.
    # @return [TokraClipboard::Native::Clipboard]
    def clipboard
      state(TokraClipboard::Native::Clipboard)
    end
  end
end

# Extend Manager when plugin is loaded
Tokra::Manager.include(Tokra::Plugins::ClipboardManagerExt)
```

## Phase 2: Image Operations

### Prerequisite: ResourceTable + Image Plugin

> [!IMPORTANT]
> Tauri's `@tauri-apps/plugin-clipboard-manager` JavaScript returns a `ResourceId` (integer) from `readImage()`, not raw bytes. The frontend then calls `image.rgba()` which invokes `plugin:image|rgba` to fetch the actual bytes.
>
> For full 1:1 parity, Tokra must implement `ResourceTable` and the core `image` plugin.

#### ResourceTable (~40 LOC Ruby)

```ruby
# lib/tokra/resource_table.rb
module Tokra
  # Manages Rust-like resources identified by integer IDs.
  #
  # Resources are stored until explicitly closed or the table is cleared.
  # This mirrors Tauri's ResourceTable for binary data like images.
  #
  # @see https://docs.rs/tauri/latest/tauri/struct.ResourceTable.html
  class ResourceTable
    def initialize
      @resources = {}
      @mutex = Mutex.new
    end

    # Add a resource and return its ID.
    # @param resource [Object] The resource to store
    # @return [Integer] The resource ID
    def add(resource)
      @mutex.synchronize do
        rid = SecureRandom.random_number(2**32)
        rid = SecureRandom.random_number(2**32) while @resources.key?(rid)
        @resources[rid] = resource
        rid
      end
    end

    # Get a resource by ID.
    # @param rid [Integer] The resource ID
    # @return [Object] The resource
    # @raise [Tokra::Error::BadResourceId] If resource not found
    def get(rid)
      @mutex.synchronize do
        @resources.fetch(rid) { raise Tokra::Error::BadResourceId.new(rid) }
      end
    end

    # Remove and return a resource.
    # @param rid [Integer] The resource ID
    # @return [Object] The removed resource
    def close(rid)
      @mutex.synchronize { @resources.delete(rid) }
    end

    # Check if a resource exists.
    def has?(rid)
      @mutex.synchronize { @resources.key?(rid) }
    end
  end
end
```

#### Wire into Manager (~10 LOC)

```ruby
# In lib/tokra/app.rb or manager module

end
```

#### Image Plugin (~50 LOC Ruby)

Implements `plugin:image|*` commands that the Tauri JS Image class calls:

```ruby
# lib/tokra/plugins/image.rb
module Tokra::Plugins
  class Image < Tokra::Plugin
    def name = "image"

    # Image data stored in ResourceTable
    ImageResource = Data.define(:width, :height, :bytes)

    def extend_api(invoke)
      case invoke.command
      when "plugin:image|new"
        # Create image from RGBA bytes
        width = invoke.payload["width"]
        height = invoke.payload["height"]
        rgba = Base64.decode64(invoke.payload["rgba"])
        image = ImageResource.new(width:, height:, bytes: rgba)
        rid = invoke.app.resources_table.add(image)
        invoke.resolve(rid)
        true
      when "plugin:image|rgba"
        # Return RGBA bytes for a resource
        rid = invoke.payload["rid"]
        image = invoke.app.resources_table.get(rid)
        invoke.resolve(Base64.encode64(image.bytes))
        true
      when "plugin:image|size"
        rid = invoke.payload["rid"]
        image = invoke.app.resources_table.get(rid)
        invoke.resolve({ "width" => image.width, "height" => image.height })
        true
      else
        false
      end
    end
  end
end
```

```ruby
  # ... existing text commands ...
  when "plugin:clipboard-manager|read_image"
    image = read_image
    if image
      rid = invoke.app.resources_table.add(image)
      invoke.resolve(rid)
```
