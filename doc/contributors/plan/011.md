# Phase 2.1: ResourceTable and Image Implementation Plan

Port Tauri's `ResourceTable` for managing resources by integer ID, and create `Tokra::Image` data class for RGBA images.

---

## Background

The `ResourceTable` is a core Tauri primitive that provides integer-based handles ("resource IDs" or "rids") for managing complex objects like images. This enables frontend JavaScript to reference binary data by integer ID rather than serializing large byte arrays through JSON.

The implementation derives from **Deno's resource system via Tauri**. Per plan 009, SPDX snippet attribution is required.

> [!NOTE]
> **Design Decision: Resource Trait Equivalent**
> 
> Tauri's Rust `Resource` trait ([resources/mod.rs:27-39](file:///Users/kerrick/Developer/tauri/crates/tauri/src/resources/mod.rs#L27)) defines:
> - `name(&self) -> Cow<'_, str>` (default: type name)
> - `close(self: Arc<Self>)` (default: no-op)
> 
> Ruby approach: **`Tokra::Resource` mixin module** with default implementations. Any object stored in `ResourceTable` should include this module. The RBS interface `Tokra::_Resource` provides type safety.

   ```ruby
   def next_rid
     loop do
       rid = SecureRandom.random_number(0xFFFF_FFFF)
       return rid unless @index.key?(rid)
     end
   end
   private :next_rid
   ```
   Tauri uses `getrandom` to generate unpredictable u32 IDs. Ruby's `SecureRandom` provides the same guarantee.

2. **Add Method** (mirrors [resources/mod.rs:93-123](file:///Users/kerrick/Developer/tauri/crates/tauri/src/resources/mod.rs#L93)):
   ```ruby
   def add(resource)
     rid = next_rid
     @index[rid] = resource
     rid
   end
   ```

3. **Get Method** (mirrors [resources/mod.rs:130-140](file:///Users/kerrick/Developer/tauri/crates/tauri/src/resources/mod.rs#L130)):
   ```ruby
   def get(rid)
     @index.fetch(rid) { raise Error::BadResourceId, rid }
   end
   ```

4. **Take Method** (mirrors [resources/mod.rs:172-176](file:///Users/kerrick/Developer/tauri/crates/tauri/src/resources/mod.rs#L172)):
   ```ruby
   def take(rid)
     resource = get(rid)
     @index.delete(rid)
     resource
   end
   ```
   Note: Tauri's `take` does NOT call `resource.close()`.

5. **Close Method** (mirrors [resources/mod.rs:210-216](file:///Users/kerrick/Developer/tauri/crates/tauri/src/resources/mod.rs#L210)):
   ```ruby
   def close(rid)
     resource = take(rid)
     resource.close if resource.respond_to?(:close)
     nil
   end
   ```
   Note: Tauri's `close` removes from table AND calls `resource.close()`.

6. **Clear Method** (mirrors [resources/mod.rs:220-222](file:///Users/kerrick/Developer/tauri/crates/tauri/src/resources/mod.rs#L220)):
   ```ruby
   def clear
     @index.clear
   end
   ```
   Note: `clear` does NOT call `close` on resources.

7. **Names Enumerator** (mirrors [resources/mod.rs:197-202](file:///Users/kerrick/Developer/tauri/crates/tauri/src/resources/mod.rs#L197)):
   ```ruby
   def names
     return enum_for(:names) unless block_given?
     @index.each do |rid, resource|

     end
   end
   ```

8. **Replace Method** (mirrors [resources/mod.rs:155-160](file:///Users/kerrick/Developer/tauri/crates/tauri/src/resources/mod.rs#L155)):

#### [NEW] [resource.rb](file:///Users/kerrick/Developer/tokra/lib/tokra/resource.rb)

Create a mixin module mirroring Tauri's `Resource` trait ([resources/mod.rs:27-39](file:///Users/kerrick/Developer/tauri/crates/tauri/src/resources/mod.rs#L27)):

```ruby
# frozen_string_literal: true

#--
# SPDX-FileCopyrightText: 2026 Kerrick Long <me@kerricklong.com>
# SPDX-License-Identifier: AGPL-3.0-or-later
#++

# SPDX-SnippetBegin
# SPDX-License-Identifier: Apache-2.0 OR MIT
# SPDX-SnippetCopyrightText: 2018-2023 the Deno authors, 2019-2024 Tauri Programme
# SPDX-SnippetComment: Resource trait adapted from tauri/crates/tauri/src/resources/mod.rs

module Tokra
  # Mixin for objects stored in ResourceTable.
  #
  # Resources are managed objects identified by integer IDs. They can be
  # stored in a ResourceTable and retrieved by their rid.
  #
  # This module provides default implementations for the resource protocol:
  # - +name+ returns the class name (for debugging)
  # - +close+ is a no-op (override for cleanup)
  #
  # Example:
  #   class MyResource
  #     include Tokra::Resource
  #
  #     def close
  #       # Custom cleanup logic
  #     end
  #   end
  #
  module Resource
    # Returns a string identifier for this resource.
    #
    # Default implementation returns the class name.
    # Override to provide a custom name for debugging.
    def name
      self.class.name || self.class.to_s
    end

    # Called when the resource is closed.
    #
    # Default implementation is a no-op.
    # Override to perform cleanup (e.g., releasing native handles).
    def close
      nil
    end
  end
end

# SPDX-SnippetEnd
```

#### [NEW] [image.rb](file:///Users/kerrick/Developer/tokra/lib/tokra/image.rb)

Create a data class mirroring Tauri's `Image` struct ([image/mod.rs:16-20](file:///Users/kerrick/Developer/tauri/crates/tauri/src/image/mod.rs#L16)):

```ruby
# frozen_string_literal: true

#--
# SPDX-FileCopyrightText: 2026 Kerrick Long <me@kerricklong.com>
# SPDX-License-Identifier: AGPL-3.0-or-later
#++

# SPDX-SnippetBegin
# SPDX-License-Identifier: Apache-2.0 OR MIT
# SPDX-SnippetCopyrightText: 2019-2024 Tauri Programme within The Commons Conservancy
# SPDX-SnippetComment: Image structure adapted from tauri/crates/tauri/src/image/mod.rs

module Tokra
  # An RGBA image in row-major order from top to bottom.
  #
  # Stores raw pixel data as bytes. Each pixel is 4 bytes (RGBA).
  # Total bytes should equal +width * height * 4+.
  #
  # Mirrors Tauri's +Image<'a>+ struct. This class includes the Resource
  # module for ResourceTable compatibility.
  #
  # Example:
  #   rgba = "\xFF\x00\x00\xFF".b  # 1x1 red pixel
  #   image = Tokra::Image.new(rgba: rgba, width: 1, height: 1)
  #   rid = table.add(image)
  #
  class Image < Data.define(:rgba, :width, :height)
    include Resource

    # Override Resource#name with specific identifier.
    def name
      "Tokra::Image"
    end

    # Images have no cleanup; close is inherited no-op.
  end
end

# SPDX-SnippetEnd
```

**Key Design Notes**:
- Uses `Data.define` per AGENTS.md Ruby standards
- Includes `Tokra::Resource` for protocol compliance
- Named `Image` (not `ImageResource`) for 1:1 Tauri naming parity
- `rgba` is a binary String (encoding: ASCII-8BIT)
- `width` and `height` are Integers

Create error class hierarchy mirroring Tauri's `Error` enum:

```ruby
# frozen_string_literal: true

#--
# SPDX-FileCopyrightText: 2026 Kerrick Long <me@kerricklong.com>
# SPDX-License-Identifier: AGPL-3.0-or-later
#++

module Tokra
  # Base error class for all Tokra errors.
  #
  # Error subclasses are nested under this class to mirror Tauri's
  # +tauri::Error+ enum structure.
  #
  # Example:
  #   begin
  #     table.get(999)
  #   rescue Tokra::Error::BadResourceId => e
  #     puts "Invalid rid: #{e.rid}"
  #   end
  #
  class Error < StandardError
    # Raised when a resource ID is not found in a ResourceTable.
    #
    # Mirrors +tauri::Error::BadResourceId(rid)+.
    class BadResourceId < Error
      # The resource ID that was not found.
      attr_reader :rid

      # Creates a new BadResourceId error.
      #
      # +rid+:: the resource ID that was not found
      def initialize(rid)
        @rid = rid
        super("Resource ID #{rid} not found")
      end
    end
  end
end
```

```rbs
module Tokra
  # Type alias for resource IDs (mirrors Tauri's pub type ResourceId = u32)
  type ResourceId = Integer

  class ResourceTable
    @index: Hash[ResourceId, Object]

    def initialize: () -> void
    def add: (Object resource) -> ResourceId
    def get: (ResourceId rid) -> Object
    def take: (ResourceId rid) -> Object
    def close: (ResourceId rid) -> nil
    def has?: (ResourceId rid) -> bool
    def clear: () -> void
    def replace: (ResourceId rid, Object resource) -> void
    def names: () -> Enumerator[[ResourceId, String], void]
             | () { ([ResourceId, String]) -> void } -> void

    private

    def next_rid: () -> ResourceId
  end
end
```
