# P1/P2 Features: Complete Tauri Parity

> Audited against `~/Developer/tauri/` for 1:1 semantics

## Ractor Shareability Requirements

Tokra's architecture (ADR 001) uses Main Ractor (UI) + Worker Ractor (logic). This creates shareability requirements:

| Component | Must Be Shareable? | Why |
|-----------|-------------------|-----|
| **All handlers** (`invoke_handler`, `setup`, `on_page_load`, `on_window_event`, `register_uri_scheme_protocol`, `on_webview_event`, `register_asynchronous_uri_scheme_protocol`) | ✅ `Ractor.shareable_proc` | Tauri requires `Send + Sync + 'static`. Handlers may be called from Worker Ractor. |
| **StateManager** | N/A (lives on Main) | But the *reason it exists* is Ractor isolation: closures can't capture outer variables. `app_handle.state(Klass)` provides explicit lookup instead. |
| **Managed state values** | ✅ Must be shareable | Sent to Worker Ractor via `Ractor.send`. Use frozen Data.define or `Ractor.make_shareable`. |
| **UriSchemeResponder** | ✅ Shareable | Must be sendable to Worker Ractor. Uses `Ractor::Port` internally. |
| **AppHandle** | ✅ Shareable | Already designed as shareable in Phase 1. |
| **Data.define types** (`PhysicalPosition`, `DragDropEvent::*`, `WebviewEvent::*`, `UriSchemeContext`) | ✅ Frozen/shareable | All use `Data.define` which produces frozen, shareable instances. |

## 1. `manage` + StateManager

**Why it exists:** Ractor blocks cannot capture outer variables. State must be registered at build-time and looked up explicitly at runtime.

**App developer usage:**
```ruby
# Builder (Main Ractor) - calls StateManager#set internally
Tokra::Builder.default
  .manage(DbConnection.new("postgres://..."))
  .manage(CacheService.new)
  .invoke_handler(&handler)
  .run

# Handler (Worker Ractor) - calls StateManager#get/try_get via AppHandle
handler = Ractor.shareable_proc do |invoke|
  db = invoke.app_handle.state(DbConnection)       # get - raises if missing
  cache = invoke.app_handle.try_state(CacheService) # try_get - returns nil if missing
  
  result = cache&.fetch(invoke.command) || db.query(invoke.payload)
  invoke.respond(result)
end
```

**Internal implementation:**
```ruby
class StateManager
  def initialize = @map = {}
  def set(state) = @map.key?(state.class) ? false : (@map[state.class] = state; true)
  def get(klass) = @map.fetch(klass)
  def try_get(klass) = @map[klass]
end
```

## 2. `on_webview_event` + DragDropEvent

```ruby
class PhysicalPosition < Data.define(:x, :y); end

module DragDropEvent
  class Enter < Data.define(:paths, :position); end
  class Over < Data.define(:position); end
  class Drop < Data.define(:paths, :position); end
  class Leave < Data.define; end
end

module WebviewEvent
  class DragDrop < Data.define(:event); end
end
```

## 3. `register_asynchronous_uri_scheme_protocol`

### UriSchemeContext
```ruby
class UriSchemeContext < Data.define(:app_handle, :webview_label); end
# app_handle: Tokra::AppHandle, webview_label: String
```

### UriSchemeResponder (shareable, single-use)
```ruby
class UriSchemeResponder < Data.define(:port, :request_id)
  def respond(response)
    raise Tokra::Error, "Already responded" if @responded
    @responded = true
    port << { request_id:, response: }
  end
end
```
