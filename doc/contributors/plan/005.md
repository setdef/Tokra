## Example Usage (mirroring Tauri helloworld)

```ruby
# Tauri (Rust):
tauri::Builder::default()
  .invoke_handler(tauri::generate_handler![greet])
  .run(tauri::generate_context!(...))

# Tokra (Ruby):
Tokra::Builder.default
  .invoke_handler { |invoke| handle_greet(invoke) }
  .run
```
