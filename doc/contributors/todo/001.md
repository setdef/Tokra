### 4. File Dialogs

**Crates:** `rfd` (Rusty File Dialogs)

#### Tauri Reference

- `plugins-workspace/plugins/dialog/src/lib.rs` — 771 lines
  - `FileDialogBuilder` with fluent API: `add_filter()`, `set_directory()`, `set_file_name()`, `set_title()`, `set_can_create_directories()`
  - **Async variants** (callback-based, safe for main thread):
    - `pick_file(callback)`, `pick_files(callback)`, `pick_folder(callback)`, `pick_folders(callback)`, `save_file(callback)`
  - **Blocking variants** (must NOT run on main thread):
    - `blocking_pick_file()`, `blocking_pick_files()`, `blocking_pick_folder()`, `blocking_pick_folders()`, `blocking_save_file()`
  - `MessageDialogBuilder` for alerts: `show(callback)` / `blocking_show()`
- `plugins-workspace/plugins/dialog/src/desktop.rs` — 258 lines
  - Uses `rfd::AsyncFileDialog` internally
  - Spawns thread for blocking operations to avoid locking main thread

#### Implementation Plan

1. **Rust:** Create `ext/tokra/src/dialog.rs`
   - Async-only API using callbacks (safe for main thread):
     - `Dialog.pick_file(options, callback)`
     - `Dialog.pick_files(options, callback)`
     - `Dialog.save_file(options, callback)`
     - `Dialog.pick_folder(options, callback)`
   - Future: Consider blocking variants run from Worker Ractor

2. **Ruby:** Create `lib/tokra/dialog.rb`
   - Thin wrapper with keyword arguments for filters, title, default path
   - Wire to `Builder#on_file_dialog` or expose via `AppHandle`

### 7. Deep Linking

**Crates:** Platform-specific

#### Tauri Reference

- `plugins-workspace/plugins/deep-link/src/lib.rs` — 557 lines
  - `DeepLink` struct with methods:
    - `get_current()` → `Option<Vec<url::Url>>` — check if app was started via deep link
    - `register(protocol)` — register app as handler for protocol (Linux/Windows only)
    - `unregister(protocol)` — unregister handler
    - `is_registered(protocol)` — check if registered
    - `register_all()` — register all schemes from config
    - `handle_cli_arguments(args)` — parse CLI for deep link arguments
  - Emits `deep-link://new-url` event when URLs arrive
  - Platform differences:
    - macOS/iOS: Uses `tao::event::Event::Opened`, registration is Info.plist-based
    - Linux: Uses `.desktop` file registration
    - Windows: Uses registry keys
  - Config in `deep-link/src/config.rs` for scheme definitions

#### Implementation Plan

1. **Rust:** Handle `tao::event::Event::Opened` in [event_loop.rs](../../../ext/tokra/src/event_loop.rs)

2. **Ruby:** Add `RunEvent::Opened` to [run_event.rb](../../../lib/tokra/run_event.rb)
   - Provide `urls` as array of strings

3. **Config:** Document Info.plist requirements for `CFBundleURLTypes`:
   ```xml
   <key>CFBundleURLTypes</key>
   <array>
     <dict>
       <key>CFBundleURLSchemes</key>
       <array>
         <string>myapp</string>
       </array>
     </dict>
   </array>
   ```
