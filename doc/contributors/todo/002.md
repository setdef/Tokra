# TODO 002: Where the port stands, and what comes next

This replaces [TODO 001](001.md), whose roadmap the plans since have
mostly carried out. Read it with the plans: each plan's inventory says
what it ported and what it deferred, and why. This document gathers the
deferrals into one list, and records how the work is done, so that
whoever picks it up next starts from the state of the code and not from
memory.

## Done

The core runtime, the IPC and asset protocols, the builder, the app and
its handle, the window's whole inherent API that tao can serve (plans
038, 040, 041, 045), menus and context menus (plan 042), the tray
(plan 043), the event system with every window event (plan 047), and the
first-party plugins in `plugins/`: clipboard, dialog, global-shortcut,
log, and notification. Standalone crate bindings live in Ferro, a
separate project of 1:1 crate-binding gems; Tokra depends on its tags.

## Next

Each item names the plan that deferred it, which holds the reason and the
sources.

- **Tray, phase 2** (plan 043): the config's `trayIcon`, and the rest of
  `cleanup_before_exit`.
- **Window and webview core plugins** (plans 045, 047): the page's
  `@tauri-apps/api/window` and `webview` commands. `onCloseRequested`
  needs `plugin:window|destroy`.
- **Child webviews and `WebviewWindow`** (plans 040, 041, 045):
  `add_child`, `Rect`, the webview rows, the traffic-light position (only
  the webview-window builder has it at the pinned commit), and
  `tauri://window-created` and `tauri://webview-created`, since Tokra
  creates no window after the first.
- **Scopes** (plan 047): the file-system scope a drop widens.
- **A zero-cost signal wake on macOS through GCD**, in place of the
  100 ms interrupt ticker (ADR 012).
- **muda: a Submenu used as a tray menu is read as a Menu.** Latent;
  found during plan 043.
- **Packaging**: port `tauri-bundler`, or wait for a bundler that handles
  native gems and bundle identifiers.
- **Windows toast identity** for the notification plugin.

## How the work is done

- **One plan per change**, written first, with an inventory against the
  pinned Tauri source, then an independent review against
  `.agents/skills/audit-parity`, then the clean gate, then the commit.
- **Windows code is linted here but runs only in CI.** Two classes of
  bug have cost the most:
  - **A native callback holding a pointer to something Ruby can free.**
    Plan 043's muda subclass outlived its menu; each window now holds
    its menus.
  - **tao re-entering itself from a nested loop.** See plan 042,
    decision 19: a `WaitUntil` deadline re-entered tao during a popup.
- **Linux runs in a `ruby:4.0.9` Debian container** with CI's packages,
  under `xvfb-run dbus-run-session`.
- **A crash seen only in CI can be replayed.** `rake test:replay` replays
  the recorded test orders and seeds in `test/fixtures/test_orders/`, and
  Windows CI runs them under cdb, which prints the native stack.
- **Real-window tests that take the keyboard** go in
  `test/integration/keyboard/` and hold the desktop input lock that other
  projects' tests on the same Mac share (plan 046). That protocol is
  meant to become a small shared gem once Tokra's and the other
  projects' copies have run cleanly for a while.
- **Tests are reliable first.** No wall-clock rate bounds: prove order,
  inject clocks, and keep timeouts only as backstops.
