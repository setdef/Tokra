### Magnus FFI Pattern for Arrays

For exposing `Vec<(String, String)>` to Ruby, use:

    fn headers(&self) -> Vec<(String, String)> {
        self.headers.clone()
    }

Magnus automatically converts this to Ruby Array of 2-element Arrays.

### Rack Header Format

Rack expects HTTP headers in CGI format: `HTTP_COOKIE`, `HTTP_ACCEPT`, etc.
The conversion is: `name.upcase.tr('-', '_')` prefixed with `HTTP_`.

Exception: `Content-Type` and `Content-Length` are NOT prefixed.

## Tauri's Header Forwarding Pattern

In [/Users/kerrick/Developer/tauri/crates/tauri/src/protocol/tauri.rs](cci:7://file:///Users/kerrick/Developer/tauri/crates/tauri/src/protocol/tauri.rs:0:0-0:0) at lines **161-163**:

```rust
for (name, value) in request.headers() {
   proxy_builder = proxy_builder.header(name, value);

```

**Key observations:**

1. **Tauri passes the entire `http::Request` object** (with headers included) to the protocol handler - it doesn't extract headers into a separate field
2. **The request already contains headers** from the underlying `wry::webview` when it enters the custom protocol handler
3. **Header iteration is straightforward** - `request.headers()` returns an iterator of [(HeaderName, HeaderValue)](cci:1://file:///Users/kerrick/Developer/tokra/ext/tokra/src/event_loop.rs:88:4-189:5) tuples

In [/Users/kerrick/Developer/tauri/crates/tauri-runtime-wry/src/lib.rs](cci:7://file:///Users/kerrick/Developer/tauri/crates/tauri-runtime-wry/src/lib.rs:0:0-0:0) at lines **4983-4991**:

```rust
webview_builder = webview_builder.with_asynchronous_custom_protocol(
  scheme,
  move |webview_id, request, responder| {
    protocol(
      webview_id,
      request,  // <-- Full Request<Vec<u8>> with headers!
      Box::new(move |response| responder.respond(response)),
    )
  },
);
```

**The critical insight:** Tauri doesn't need to explicitly extract headers because the [request](cci:1://file:///Users/kerrick/Developer/tokra/ext/tokra/src/events.rs:107:4-111:5) object passed by wry's `with_asynchronous_custom_protocol` already includes them. They just pass the entire request through.
