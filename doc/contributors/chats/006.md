# lib/tokra/native/events.rb
module Tokra::Native

## Why Rust Events Might Exist

Looking at the code flow in [event_loop.rs](cci:7://file:///Users/kerrick/Developer/tokra/ext/tokra/src/event_loop.rs:0:0-0:0):

```rust
UserEvent::IpcMessage(msg) => {
    let event_obj = RbIpcEvent::new(msg);  // Create Rust-wrapped Ruby object
    let _ = callback.funcall::<_, _, Value>("call", (event_obj,));
}
```

Rust *could* instead:

```rust
UserEvent::IpcMessage(msg) => {
    // Option A: Pass raw data, let Ruby construct the event
    let _ = callback.funcall::<_, _, Value>("call", ("ipc", msg));
}

// Or Option B: Instantiate Ruby's Data.define class directly
UserEvent::IpcMessage(msg) => {
    let ipc_event_class = /* get Tokra::Native::IpcEvent from Ruby */;
    let event_obj = ipc_event_class.funcall::<_, _, Value>("new", (msg,));
    let _ = callback.funcall::<_, _, Value>("call", (event_obj,));
}
```

## Analysis: No Good Reason for Rust Events

| Concern | Rust Events | Ruby Data.define |
|---------|-------------|------------------|
| Lines of code | ~300 | ~10 |
| Ractor-shareable | Needs `frozen_shareable` flag | ✅ Automatic (Data is immutable) |
| Adding predicates | Rust method + Magnus binding | Just Ruby |
| Tests | Rust tests (cargo test) | Ruby tests (minitest) |
| Performance | Slightly faster construction | Negligible difference |
| Type safety | Compile-time in Rust | Runtime in Ruby |

**The type safety argument is weak** — the types are only checked at the Rust boundary anyway, and Ruby will use duck typing regardless.

---

## Conclusion

**No, there's no good reason.** This appears to be an oversight or early-stage choice that wasn't revisited.

Moving events to Ruby `Data.define` would:
1. ✅ Delete ~300 lines of Rust
2. ✅ Align with ADR 001's "thin binding" goal
3. ✅ Make events automatically Ractor-shareable
4. ✅ Use idiomatic Ruby

The Rust side would shrink to:
- `UserEvent` enum (internal transport, ~50 lines)
- Event loop dispatch that passes primitives to Ruby

**This is a legitimate refactoring opportunity to bring Rust closer to the ~500 LOC target.**

// In proxy.rs - respond directly instead of going through event loop
pub fn respond(&self, request_id: u64, status: u16, headers: Vec<(String, String)>, body: String) {
    if let Some(responder) = get_responders().lock().unwrap().remove(&request_id) {

            .status(status)

            .body(body.into_bytes());

    }
}
