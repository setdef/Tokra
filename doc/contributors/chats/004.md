### Magnus FFI Pattern for Arrays

For exposing `Vec<(String, String)>` to Ruby, use:

    fn headers(&self) -> Vec<(String, String)> {
        self.headers.clone()
    }

Magnus automatically converts this to Ruby Array of 2-element Arrays.

### Rack Header Format

Rack expects HTTP headers in CGI format: `HTTP_COOKIE`, `HTTP_ACCEPT`, etc.
The conversion is: `name.upcase.tr('-', '_')` prefixed with `HTTP_`.

Exception: `Content-Type` and `Content-Length` are NOT prefixed.
