= tokra-clipboard

{rdoc-image:https://github.com/setdef/Tokra/actions/workflows/ci.yml/badge.svg?branch=trunk}[https://github.com/setdef/Tokra/actions/workflows/ci.yml]

Clipboard plugin for Tokra desktop applications.

Provides read/write access to the system clipboard using the arboard crate,
and serves the commands of Tauri's clipboard-manager plugin, so the frontend
can use <tt>@tauri-apps/plugin-clipboard-manager</tt> unchanged.

== Installation

Installing the gem compiles a Rust extension with <tt>cargo --locked</tt>
against the shipped +Cargo.lock+, which needs Rust 1.85 or newer (1.99 or
newer on macOS 27). Set +RB_SYS_EXTRA_CARGO_ARGS+ to replace
<tt>--locked</tt>, for example with an empty string to resolve newer
dependency versions.

== Usage

Register the plugin on the app handle, for example in the setup hook. It
stores a native clipboard in managed state, reachable from any manager as
+clipboard+:

  Tokra::Builder.new
    .setup { |app| app.handle.plugin(Tokra::Plugins::Clipboard::Plugin.new(app.handle)) }
    .run

  # Later, with the handle:
  handle.clipboard.write_text("Hello, World!")

  # Or through the plugin, which raises Error::Clipboard on failure:
  plugin = Tokra::Plugins::Clipboard::Plugin.new(handle)
  plugin.write_text("Hello, World!")
  plugin.read_text   # raises Error::Clipboard when the clipboard is empty
  plugin.clear

Every failure is a Tokra::Plugins::Clipboard::Error::Clipboard carrying
arboard's message, as in Tauri. The clipboard is cleaned up when the app
exits.

== Features

- Read and write text, HTML, and images
- Tauri-compatible IPC commands: read_text, write_text, read_image,
  write_image, write_html, clear
- Cross-platform support (macOS, Windows, Linux)
- Native performance via Rust bindings
