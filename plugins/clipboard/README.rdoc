= tokra-clipboard

Clipboard plugin for Tokra desktop applications.

Provides read/write access to the system clipboard using the arboard crate.

== Usage

  Tokra::Builder.new
    .plugin(Tokra::Plugins::Clipboard.new)
    .run

  # In your app:
  clipboard = Tokra::Plugins::Clipboard.new(app)
  text = clipboard.read_text
  clipboard.write_text("Hello, World!")
  clipboard.clear

== Features

- Read and write text to the system clipboard
- Cross-platform support (macOS, Windows, Linux)
- Native performance via Rust bindings
