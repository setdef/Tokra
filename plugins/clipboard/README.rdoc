= tokra-clipboard

{rdoc-image:https://justin.searls.co/img/shovelware.svg}[https://justin.searls.co/shovelware/]
{rdoc-image:https://github.com/setdef/Tokra/actions/workflows/ci.yml/badge.svg?branch=trunk}[https://github.com/setdef/Tokra/actions/workflows/ci.yml]

Clipboard plugin for Tokra desktop applications.

Reads and writes the system clipboard through ferro-arboard, a one-to-one
Ruby binding of the arboard crate, and serves the commands of Tauri's
clipboard-manager plugin, so the frontend can use
<tt>@tauri-apps/plugin-clipboard-manager</tt> unchanged.

== Installation

tokra-clipboard is pure Ruby. Its clipboard comes from ferro-arboard, which
compiles a Rust extension when it installs (its README names the Rust
versions). ferro-arboard is not on RubyGems.org yet, so name its release tag
in your Gemfile beside this gem:

  gem "ferro-arboard", git: "https://github.com/setdef/Ferro",
    tag: "ferro-arboard/v0.1.0.pre.2", glob: "gems/*/*.gemspec"
  gem "tokra-clipboard"

== Usage

Register the plugin on the app handle, for example in the setup hook. It
stores a Tokra::Plugins::Clipboard::Clipboard in managed state, reachable
from any manager as +clipboard+:

  Tokra::Builder.new
    .setup { |app| app.handle.plugin(Tokra::Plugins::Clipboard::Plugin.new(app.handle)) }
    .run

  # Later, with the handle:
  handle.clipboard.write_text("Hello, World!")

  # Or through the plugin, which raises Error::Clipboard on failure:
  plugin = Tokra::Plugins::Clipboard::Plugin.new(handle)
  plugin.write_text("Hello, World!")
  plugin.read_text   # raises Error::Clipboard when the clipboard is empty
  plugin.clear

Every failure is a Tokra::Plugins::Clipboard::Error::Clipboard carrying
arboard's message, as in Tauri. The clipboard is cleaned up when the app
exits.

On Linux, the app serves what it copied for as long as it runs. When it
exits, arboard offers the contents to the desktop's clipboard manager and
waits at most 100 ms, as in Tauri, so a busy manager can miss them.

== Features

- Read and write text, HTML, and images
- Tauri-compatible IPC commands: read_text, write_text, read_image,
  write_image, write_html, clear
- macOS, Windows, and Linux (X11 and Wayland)
