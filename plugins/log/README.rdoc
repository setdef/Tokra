= tokra-log

Logging plugin for Tokra desktop applications.

Wraps Ruby's Logger with desktop-friendly defaults and integrates with
Tokra's plugin lifecycle.

== Usage

Build the plugin with Tokra::Plugins::Log::Builder and register it on the
app handle from the setup hook, before the window opens:

  require "pathname"
  require "tokra"
  require "tokra-log"

  Tokra::Builder.default
    .setup(&Ractor.shareable_proc { |app|
      log = Tokra::Plugins::Log::Builder.new
        .level(:info)
        .targets([Tokra::Plugins::Log::Target.new(Pathname("app.log"))])
        .build
      app.handle.plugin(log)
    })
    .run

== Configuration

Each Builder method returns the builder, so calls chain:

- +level+:: minimum level (+:trace+, +:debug+, +:info+, +:warn+, +:error+, +:fatal+; default +:debug+)
- +targets+, +target+:: where messages go: a Target wrapping an IO, a
  Pathname, or a TargetKind (such as TargetKind::LogDir)
- +rotation_strategy+, +max_file_size+, +timezone_strategy+:: file handling
- +format+, +filter+:: a Ractor-shareable formatter or filter for every target
